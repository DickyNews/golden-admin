Batasan arsitektur

Admin Web tidak menyimpan atau menjalankan Golden Engine.

Admin Web hanya menjadi control plane: membaca dan mengubah data melalui API. Golden Engine, queue, database, coin authority, autentikasi server, dan proses video tetap berada di backend/VPS. Customer Web tetap menjadi frontend customer.
